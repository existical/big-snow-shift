# Big Snow Shift

**with Uncle Bolyus**

A Christmas snow-clearing game by Existical Games. Clear the stairs, watch for falling icicles, and welcome Santa before midnight.

## Start playing

On Windows, extract the entire ZIP and open **BigSnowShift.exe**. Keep **BigSnowShift.pck** beside it. No Godot installation is needed.

Choose **New game**, select Easy, Medium, Hard or Extreme, and start. Each preset has three rounds. Custom games let you choose one to three rounds and adjust the rules before starting.

Hold beside Uncle Bolyus to move and shovel automatically. When all the snow is cleared, walk to the glowing door to meet Santa.

## Controls

| Action | Control |
| --- | --- |
| Move and shovel | Hold the mouse button or a finger beside Uncle Bolyus; drag to turn and release to stop |
| Keyboard movement | Arrow keys or WASD |
| Controller movement | Left stick or D-pad |
| Pause / resume | Corner pause/play button, Escape, P or controller Start |
| Windows fullscreen | F11, Alt+Enter or Settings → Fullscreen |

An optional on-screen control pad is available in Settings. Music, effects and language can also be changed there. Game rules stay fixed until you start a new game.

## Saves and scores

Unfinished games save automatically. **Continue game** restores a saved game at a pause screen. Finishing or losing removes that Continue save; after a loss you can immediately retry the round from its result screen.

After a win, enter a name to save your score. If you leave first, **Save my score** on the main menu reopens name entry. The game also reopens it on your next launch.

Scores, settings and progress stay on your device. Windows saves use `%APPDATA%\Godot\app_userdata\Big Snow Shift\`. Removing the downloaded game files does not remove these saves.

## Privacy and support

The game works offline, contains no advertisements or in-app purchases, and does not upload nicknames, scores or saves. **Settings → Privacy policy** provides the full policy offline. A copy is also included as **PRIVACY_POLICY.txt**.

For support, contact **existicalgames[at]gmail[dot]com**. Please include your game version, operating system and a description of the problem. Avoid sending sensitive information.
